# Resume PDF fonts

Static Latin WOFF files from Fontsource 5.3.0 are embedded by the local PDF
exporter so output does not depend on operating-system fonts or a network
request. The included families are Merriweather, Gelasio, Tinos, Inter, Arimo,
and Carlito. Each family is distributed under the SIL Open Font License 1.1;
its corresponding `*-LICENSE.txt` file is included in this directory.
