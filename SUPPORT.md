# Support

- For a reproducible bug, use the bug report form and include synthetic sample data only.
- For an enhancement, use the feature request form and describe the job-to-be-done before proposing an implementation.
- For setup or usage questions, use the question form.
- For vulnerabilities, follow `SECURITY.md` and do not open a public issue.

PrivaCV is maintained on a best-effort basis. Please search existing issues before filing a new one. Never attach a real resume, application record, browser database, or exported backup to a public issue.
